# Distinct task (owner, 2026-11-08): Global event dashboard, at the TOP of the main page
Owners: design (spec, tokens, data asset in ewb_live/viz) + frontend (implementation in dashboard/*.js). Coordinate in notes/channel_design_frontend.md. Track it separately from other work and post 'GLOBAL DASHBOARD READY' with screenshots when live.
Requirements:
1. A global map at the top of the home page showing ALL events of the last 90 days (heat waves, freezes, ARs), in the **Equal Earth projection** (use d3-geo `geoEqualEarth`, vendored, on SVG or canvas; Leaflet can't do Equal Earth). Land and coastlines from vendored Natural Earth (110m or 50m), styled to the OWB light/dark tokens; subtle graticule.
2. **Time slider** across the 90-day window (daily steps; play/pause; drag; keyboard arrows). At each date it shows the events active that day, drawn as their actual daily footprints (heat: cells above p85, freeze: below p15, AR: the AR mask), colored by type (heat warm orange-red, freeze blue, AR green tokens), with the event box as a faint outline. Optional 'all' mode shows every event's full extent at once.
3. **Select one or more events** at the same time: click events on the map or toggle them in a compact list/legend; selected events are highlighted (others dimmed); multi-select supports comparing concurrent or sequential events; the selection persists in the URL (e.g. #global=ids&date=YYYY-MM-DD). Each selected event has a link that opens its existing event detail page (the same behavior as clicking in the list); Back returns to the global view with its state.
4. Filters by event type (shared with the page's type tabs), a date readout, a type legend, and a small timeline strip under the slider showing when each event was active (a Gantt-like strip of bars colored by type; clicking a bar selects that event and jumps the slider).
5. Responsive: full container width (within the new <=75vw max container); usable on mobile (tap to select, slider thumb >= 44 px).
6. Performance: a lightweight data asset. design builds `data/results/global_timeline.json` (per event: id, type, title, dates, bbox, and per-day simplified footprint polygons or coarsened u8 masks, e.g. 0.5-1 deg, target < 1-2 MB total), generated on the box after selection with the other viz assets (add it to the auto-viz step so ids never drift). Render with canvas if SVG gets heavy.
7. Accessibility: keyboard operable, ARIA labels, reduced-motion respected for playback.
8. Tests (frontend): Playwright: slider moves and the active-event count changes; multi-select via map and list; URL state round trip; open an event and come Back to the same global state; 404 on the asset shows a graceful message.
